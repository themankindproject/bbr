Deployment environment internal endpoints
-----------------------------------------
The published Pipelines API exposes only the environment *variables*
(`/deployments_config/environments/{uuid}/variables`). Atlassian staff on the
community forum: "we've released these to the public API now ... Our internal
endpoints do not have a deprecation policy." bbr uses the internal
`/deployments_config/environments/{uuid}/changes` endpoint for trigger/history;
it is kept, and 404s now explain the dependency and point at `bbr ci trigger`.
https://community.atlassian.com/forums/Bitbucket-questions/How-to-get-deployment-environments-variables/qaq-p/1193946
